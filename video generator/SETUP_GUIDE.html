🎬 API Setup Guide

Get your D-ID and Tavus API keys configured in 5 minutes

🎭 D-ID Setup

D-ID provides realistic AI avatars that can deliver your message with natural animations.

Getting Your D-ID API Key

  1. Visit D-ID Platform
  2. Click "Sign Up" and create a free account (no credit card required for trial)
  3. Verify your email address
  4. Go to Settings → API Keys
  5. Click "Create API Key" and copy the generated key
  6. Paste the key into the Video Generator settings
✅ Free Tier Includes: 5 videos/day, Multiple avatars, Voice options

⚙️ Configuring the Video Generator

Step 1: Open the Application

Open index.html in your web browser. You should see the Video Generator interface.

Step 2: Access Settings

When you first load the app, a settings dialog will appear asking for your API keys. If not:

Look for a settings icon or menu option to configure your API keys.

Step 3: Enter Your Keys

  1. Copy your D-ID API key and paste it into the "D-ID API Key" field
  2. Copy your Tavus API key and paste it into the "Tavus API Key" field
  3. Click "Save Settings"
✅ Your keys are saved locally in your browser. You won't need to enter them again.

Step 4: Test Your Setup

  1. Enter a short test message (e.g., "Hello, this is a test video")
  2. Select an avatar and voice
  3. Choose a video style
  4. Click "Generate Video"
  5. Wait for processing (usually 1-3 minutes)
  6. Preview and download your video!

🔧 Troubleshooting

API Key Not Working

Problem: "Invalid API Key" error
  • Double-check that the key was copied completely
  • Remove any extra spaces at the beginning or end
  • Verify the key is still active in your provider's dashboard
  • Try generating a new API key from the provider

Video Generation Timeout

Problem: Video generation never completes
  • Check your internet connection
  • Try with a shorter text (less than 100 words)
  • Verify the API service is operational
  • Check if you've reached your monthly/daily limit

Video Won't Download

Problem: Download button doesn't work
  • Check if your browser is blocking downloads
  • Disable any ad blockers or privacy extensions
  • Try a different browser
  • Clear browser cache and try again
